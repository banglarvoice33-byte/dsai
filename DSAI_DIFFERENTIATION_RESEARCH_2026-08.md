
## Official agent workflow evidence

5. GitHub Docs, “About GitHub Copilot code review”: https://docs.github.com/en/copilot/concepts/agents/code-review

GitHub positions agent review as a reviewable workflow: it identifies issues, suggests fixes that a human can apply, offers multiple review-effort levels, and explicitly warns that feedback is not guaranteed to be correct and must be supplemented with human review. This supports DSAI’s human-gated positioning, but also shows the opportunity to make review quality, evidence, confidence, and next actions more explicit in every workflow.

## Official trust and risk-management evidence

6. NIST, “Artificial Intelligence Risk Management Framework: Generative Artificial Intelligence Profile”: https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence

NIST describes the profile as a cross-sector resource intended to help organizations incorporate trustworthiness considerations into the design, development, use, and evaluation of generative-AI products and systems. This supports making DSAI’s strongest differentiator an operational trust layer—clear scope, review gates, evidence, monitoring, and recovery—not merely a Bengali interface.
