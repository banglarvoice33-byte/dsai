# Decisions

- Preserve the existing React/Vite + Wouter + Express/tRPC architecture and route names.
- Keep the AI Hub catalog intact; no arbitrary provider records or fake runtime integrations.
- Show directory entries as “তালিকাভুক্ত”; show only providers in the existing runtime capability boundary as “DSAI-তে চালু”.
- Count catalog entries and runtime connectors separately.
- Keep search keyword-based and transparent; no claim of semantic AI search.
- Use URL query parameters for shareable AI Hub filters without a full navigation.
- Work Desk, dashboard and public-site changes must reuse existing product flows and data.
- Do not change production deployment or external billing settings as part of this visual refresh.
